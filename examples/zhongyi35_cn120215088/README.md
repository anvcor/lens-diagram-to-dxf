# 中一 AF 35mm F1.4：专利缺非球面系数时的还原（CN120215088 A 实施例 2）

**问题**：专利印了完整的 R / D / Nd·Vd 和对焦间隔（34mm F1.45，15 片），17、18、28、29 四个面标为
「非球面」，但全文**一个系数都没有**。按常规流程这件专利做不了。

**思路**：专利的结构图（图 3）通常是 CAD 按比例直接导出的。先用印刷的 R/D 把图标定准，再逐行量非球面
墨线相对「印刷顶点球面」偏了多少，就得到非球面的初值。然后只用 INF 一个组态优化初始结构，最后交给人在
CODE V 里手工修正。

## 1. 标定 + 量偏离（`scripts/asph_from_diagram.py`）

```bash
python3 ../../scripts/diag_extract.py fig3.png -o lens.json --length 107 ...   # 先拿到 pxmm / 光轴 / 第一面顶点的初值
python3 ../../scripts/asph_from_diagram.py lens.json presc.json -o asph.json --seq asph_snippet.seq
```

- `presc.json`：专利面表，内容是 id / R / D，`asph` 列出缺系数的面。
- 标定只用球面，取的是光轴附近 h=7..14 px 的墨线。本图标定结果为 **9.2175 px/mm**，368 点残差 0.31 px（约 0.03 mm）。
- 球面的偏离 rms 中位数 0.066 mm，这就是这张图的读数噪声。非球面偏离要比它大得多才可信。
- 量到的非球面边缘偏离（+ 指向像方）：

| 面 | 印刷 R | 边缘 Δz | 意义 |
|---|---|---|---|
| 17 | 71.94 | +0.01 mm @ 18 | L25 前面，几乎是球面 |
| 18 | −40.33 | +0.28 mm @ 18 | L25 后面，边缘变薄 |
| 28 | −73.85 | −1.45 mm @ 16.4 | L45 两面同向大幅弯折 |
| 29 | −178.18 | −1.41 mm @ 16.5 | （校场曲/畸变的主力面） |

- 只加这组图测初值，轴上光斑就从纯球面时的 >1 mm 降到约 10 µm。这说明初值方向是对的，缺系数的这几个面确实是主力校正面。
- `asph_snippet.seq` 可以直接 `in` 进 CODE V。面号是 presc.json 里的顺序号，要自己对一下 CODE V 的面号；这里 CODE V 面号 = 专利序号 − 1。

## 2. 初始结构优化：只用 INF 一个组态

**这一步踩过坑**：第一次把 INF 和 MFD（最近对焦态）一起放进拟合目标，结果 MFD 抢走了 INF 的性能，INF
子午场曲始终比专利差约 +0.05 mm。

还原或重建时**只优化 INF**。近距组态等 INF 定型以后，再用对焦组位置解补上，只用于交付。

## 3. 转人工修正：`opt_macro_example.seq`

初始结构出来以后，交给设计者在 CODE V 里手工修正：自己设变量、放开口径、设渐晕点、换玻璃。宏只放约束，写法照抄这个例子：

- `EFL Z1` 上下限，`DIY` 全视场畸变上下限；
- 球面：**RDY 取原值 ±5%**，传统做法；
- 非球面：顶点 R 可变，但用 RDY 限制在**与专利同号、|R| 30..500** 之间，500 是加工极限；
- 少量 ET / THI 约束，以及 `INT NO / MXC / MNC / EFT TA / DRA / EFP ALL Y / MNT / MNE / MNA`，可选 `GLA` 替换表；
- **宏里不设变量**，变量由设计者在镜头里设；**只有 INF 一个组态**；对焦间隔用镜头里的求解（如 OAL），不写进宏。

不要这样做：

- **用 SAGF 约束边缘矢高**：设计者放开口径、设渐晕点后，矢高约束就失效了。
- **让非球面顶点 R 不受限制**：优化会让 R 变号，再靠高次项把面形掰回来，整片镜子弯反（实测 S27 −73.8 → +23.2）。
- **一次塞很多约束**：比如图上量的矢高带、像差图上读的场曲目标、拐点控制、MTF 型误差函数，结果全都不好用。

`CIR_axial.seq` 是一个设置步骤（CIR 不是 AUT 变量，所以没法写成约束）：把指定面范围的 CIR 设成轴上 ±1 光瞳边缘光线的高度。如果对所有面都用，离轴视场会被完全挡死。

## 4. 专利数据疑点（记下来，别硬凑）

- 最近态印的 Fno 1.34，比无穷远还亮，应该是印错。按光阑固定算是 1.554。
- 「227 mm」和印刷的 D1/D2 对不上：按物到像面理解不可能，按峰位反推，物到第一面是 233 mm。
